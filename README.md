# Zenhance Labs website

Zenhance Labsのプロダクト入口サイトです。GitHub Pagesで配信する、依存関係のない静的サイトとして構成しています。

## Products

- [TATSU](https://zenhancelabs.github.io/tatsu-website/) — がんばらなくていいデジタルデトックス
- [Fitlet](https://zenhancelabs.github.io/fitlet-website/) — ちょっと動くを、習慣に

## Design direction

指定された [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) のVercel分析を出発点に、黒インクと余白を中心にした独自のレイヤーへ調整しています。メッシュグラデーションはヒーローの一箇所だけに使い、プロダクト導線と読みやすさを優先しています。詳細は [DESIGN.md](DESIGN.md) にまとめています。
