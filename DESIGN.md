# Zenhance website design

The page follows the Apple analysis in [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md/tree/main/design-md/apple), adapted for Zenhance's two products.

## Rules we are following

- Product imagery is the main visual. Use the real app screens and product characters before adding decoration.
- Use full-width rectangular product tiles with alternating dark and light surfaces.
- Use the system font stack (`-apple-system`, SF Pro where available, and Japanese system fonts). Do not load a decorative web font.
- Keep the interface chrome quiet: no decorative mesh gradients, no glass panels, no card shadows, and no numbered labels.
- Use Action Blue `#0066cc` as the only interaction color.
- Reserve the single soft product shadow for screenshots and character imagery resting in a tile.
- Keep copy in Japanese. Product names are the only prominent Latin text.
- Let whitespace and the product assets create the rhythm.
